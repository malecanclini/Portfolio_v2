Pet Adoption - Encuentra tu Mascota Ideal

Frontend

  • Interfaz responsive y accesible

Weather App - Pronóstico Meteorológico

Frontend

Aplicación de clima que permite consultar el pronóstico en cualquier ciudad o en tu ubicación actual. Utiliza APIs de datos meteorológicos para proporcionar información precisa y actualizada en tiempo real.

Características:
  • Búsqueda de clima por ciudad
  • Geolocalización automática
  • Pronóstico extendido (5-7 días)
  • Indicadores meteorológicos completos
JavaScript API REST HTML5/CSS3 Geolocation API

Dónde Denunciar - Recursos para la Atención y Denuncia de Violencia de Género en Paraguay

SIG / WebGIS

Aplicación geoespacial interactiva desarrollada para centralizar información sobre recursos de atención, protección y denuncia para mujeres en situación de violencia de género en Paraguay.

Características:
  • Mapa interactivo con localización de servicios.
  • Búsqueda y filtrado por categorías.
  • Acceso rápido a teléfonos de emergencia.
  • Información detallada de centros de atención.
  • Diseño responsive para dispositivos móviles.
Leaflet OpenStreetMap JavaScript HTML5 CSS3 GIS
